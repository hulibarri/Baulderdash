# HunterDASH

Family Balderdash, HunterDASH edition, with all the classic categories: Weird Words, Peculiar People, Incredible Initials, Marvelous Movies, Laughable Laws and Daring Dates. Everyone plays on their own phone. The host creates a room and the others join with a 4-letter code or an invite link. There's also a one-phone mode, played on paper or by passing the phone around.

Play it: https://hulibarri.github.io/Baulderdash/

Rooms connect phone-to-phone using PeerJS (`peerjs.min.js`, v1.5.4, MIT). The host's phone runs the game, so keep it open while you play.
